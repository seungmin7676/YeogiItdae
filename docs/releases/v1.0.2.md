로그인 화면과 처음 사용 안내를 다듬었습니다. 작은 화면이나 큰 글씨 설정에서도 화면이 잘리지 않도록 손봤습니다.

- 로그인 화면을 정리하고 회원가입을 별도 화면으로 나눴습니다.
- 처음 사용 안내의 디자인을 바꿨습니다. **마이페이지 → 튜토리얼 다시 보기**에서 언제든 다시 볼 수 있습니다.
- 분실물·습득물 필터와 처음 채팅방에 들어갈 때 생기던 오류를 수정했습니다.
- 채팅방 위쪽에서 관련 게시글을 확인할 수 있도록 다듬었습니다.
- 차단된 상대와의 채팅에서 표시되던 전송 오류 안내를 정리했습니다.
- 로고의 배경과 색상을 정리했습니다.
