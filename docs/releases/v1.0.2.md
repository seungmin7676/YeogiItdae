## 변경 사항

- 로그인 화면 정렬 개선 및 회원가입 화면 분리
- 튜토리얼 디자인 변경
- 마이페이지에 **튜토리얼 다시 보기** 메뉴 추가
- 작은 화면과 큰 글꼴 설정에서 화면 잘림 개선
- 채팅방 상단의 게시글 상세 보기 개선
- 로고 배경 및 색상 정리

## 수정 사항

- 분실물·습득물 필터 오류 수정
- 첫 채팅방 진입 오류 수정
- 차단된 상대와의 채팅에서 전송 오류 안내 처리 수정
