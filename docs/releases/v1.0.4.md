# 여기있대! v1.0.4 — 채팅과 물건 목록을 더 편하게

어떤 물건에 대한 대화인지 바로 확인하고, 아직 진행 중인 글을 쉽게 찾을 수 있도록 개선했습니다.

> 이번 사전 릴리즈는 **변경 내역과 소스 코드 공개용**이며, 새 Android APK는 첨부하지 않았습니다.
> 설치 가능한 앱은 [v1.0.3 릴리즈](https://github.com/seungmin7676/YeogiItdae/releases/tag/v1.0.3)에서 받을 수 있습니다.
> 아래 화면 개선을 휴대폰에서 사용하려면 이 소스로 빌드한 새 APK가 필요합니다.

## 채팅에서 물건을 더 쉽게 확인해요

- 채팅 목록에 **물건 제목**을 표시해 같은 상대와 여러 대화를 해도 구별할 수 있습니다.
- 최근 대화 시각과 **진행·확인·전달 완료·게시글 삭제 상태**를 함께 표시합니다.
- 채팅방 상단에 물건 사진, 제목, 상태와 **게시글 보기**를 표시합니다. 사진이 없거나 게시글이 삭제된 경우도 안내합니다.
- 대화에 날짜 구분선을 표시해 언제 나눈 이야기인지 쉽게 확인할 수 있습니다.
- 이전 대화를 읽는 중 새 메시지가 오면 현재 위치를 유지하고 **새 메시지** 버튼으로 최신 대화에 이동할 수 있습니다.

## 원하는 글을 더 쉽게 찾아요

- 홈에 **진행 중만** 필터를 추가했습니다. 완료된 글을 제외한 상태에서 검색·장소·카테고리·정렬을 함께 사용할 수 있습니다.
- 물건 목록에서 장소와 작성자·시간 정보를 나눠 표시해 긴 장소 이름도 읽기 편하게 정리했습니다.

## 메시지 전송 오류를 고쳤어요

- 상대가 보낸 메시지와 같은 내용으로 답장할 때 권한 오류로 전송되지 않던 문제를 수정했습니다.
- 같은 문구를 연속해서 보내거나 같은 장수의 사진을 이어 보낼 때도 전송할 수 있도록 수정했습니다.
- 이 전송 오류의 서버 수정은 운영 환경에 반영했습니다. **기존 APK에서도 새 설치 없이 적용됩니다.**

## 앱 안내를 쉽게 정리했어요

- README를 앱 소개, 설치·가입, 분실물 찾기, 습득물 등록과 화면별 사용 방법 중심으로 다시 작성했습니다.
- 버전별 업데이트 내용은 GitHub 릴리즈에서 확인하도록 정리했습니다.

## 검증 및 배포 범위

- Flutter 테스트 150개 및 정적 분석 통과

- 진행 중 필터의 운영 조회 조합 16개 확인 및 필요한 인덱스 반영 완료

이 체크아웃에는 기존 APK 서명 설정이 없어 설치 파일을 첨부하지 않았습니다.
