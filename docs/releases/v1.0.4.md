> **알려진 문제:** 이 버전의 Android 앱에서 시작 오류 발생. [v1.0.5](https://github.com/seungmin7676/YeogiItdae/releases/tag/v1.0.5)에서 수정.

## 추가 기능

- 채팅 목록에 물건 제목, 마지막 대화 시간, 진행 상태 표시
- 채팅방 상단에 물건 사진·제목·상태 및 **게시글 보기** 추가
- 대화 날짜 구분선 및 **새 메시지** 이동 버튼 추가
- 홈에 **진행 중만** 필터 추가

## 개선 사항

- 이전 대화를 읽는 중 새 메시지 수신 시 스크롤 위치 유지
- 삭제된 게시글의 상태 표시
- 물건 목록에서 장소와 작성자·시간 정보를 분리해 표시

## 수정 사항

- 상대방과 같은 내용의 메시지를 보낼 때 발생하는 권한 오류 수정
- 같은 문구 또는 같은 장수의 사진을 연속 전송할 때 발생하는 오류 수정

채팅 전송 오류 수정은 서버에 적용되어 이전 앱 버전에서도 별도 업데이트 없이 반영됩니다.

## 다운로드

Android 앱은 실행 오류가 수정된 [최신 버전](https://github.com/seungmin7676/YeogiItdae/releases/latest) 이용.
