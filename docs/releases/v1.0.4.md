> 이 버전의 Android 앱에는 실행되지 않는 문제가 있습니다. 아래 첨부 파일 대신 [최신 버전](https://github.com/seungmin7676/YeogiItdae/releases/latest)을 설치해 주세요. v1.0.5에서 수정했습니다.

같은 사람과 여러 물건에 대해 이야기할 때 대화를 구분하기 어렵다는 점을 고쳤습니다.

- 채팅 목록에 물건 제목, 마지막 대화 시간, 진행 상태를 표시합니다.
- 채팅방 위쪽에 물건 사진과 제목을 넣었습니다. **게시글 보기**를 누르면 원래 글로 이동할 수 있고, 삭제된 글은 삭제 상태로 표시됩니다.
- 대화 사이에 날짜가 표시됩니다. 이전 내용을 읽을 때 새 메시지가 와도 화면이 갑자기 내려가지 않고, **새 메시지** 버튼으로 이동할 수 있습니다.
- 홈에 **진행 중만** 필터를 추가했습니다. 이미 완료된 글을 빼고 찾아볼 수 있습니다.
- 목록에서 장소와 작성자·시간을 나눠 표시해 긴 장소 이름도 읽기 편하게 바꿨습니다.

상대가 보낸 말과 똑같이 답장하면 “권한이 없어 처리할 수 없어요”가 뜨던 오류도 고쳤습니다. 같은 문구나 같은 장수의 사진을 이어 보낼 때 생기던 문제도 함께 수정했습니다. 이 채팅 오류 수정은 이전 앱에도 별도 업데이트 없이 적용됩니다.

설치 없이 쓰려면 [웹 버전](https://yeogi-itdae.web.app)을 이용해 주세요.
