# 여기있대! v1.0.5 — Android 앱 실행 오류 수정

v1.0.4를 설치한 뒤 **“앱을 시작할 수 없어요”**라는 화면에서 더 진행되지 않던 문제를 수정했습니다. 이 오류는 인터넷 연결 상태와 관계없이 발생할 수 있었습니다.

## Android 설치

아래 **Assets**에서 `YeogiItdae-v1.0.5.apk`를 다운로드해 설치해 주세요. Android 7.0 이상이 필요합니다.
기존 앱과 같은 서명 키를 사용하므로 **기존 앱을 삭제하지 않고 업데이트**할 수 있습니다.
`Source code`는 설치 파일이 아닙니다. 웹에서 사용하려면 [여기있대! 웹 버전](https://yeogi-itdae.web.app)을 열어 주세요.

## 수정 내용

- v1.0.4 APK에서 빠졌던 Flutter 플러그인 등록 파일을 포함해 Firebase 초기화가 정상적으로 진행되도록 수정했습니다.
- 향후 플러그인 등록 파일이 누락되면 릴리즈 빌드가 중단되도록 검사 절차를 추가했습니다.
- v1.0.4에서 추가된 채팅과 물건 목록의 편의 기능도 이용할 수 있습니다.

## 확인한 내용

- 기존 v1.0.3·v1.0.4 APK와 서명이 같은지 확인했습니다.
- Android 9 휴대폰에서 v1.0.4를 삭제하지 않고 v1.0.5로 업데이트했습니다.
- 기존 로그인 상태가 유지되고 홈 화면과 물건 목록이 표시되는 것을 확인했습니다.
- 플러그인 등록 파일이 없을 때 릴리즈 빌드가 실패하는지 검증했습니다.
