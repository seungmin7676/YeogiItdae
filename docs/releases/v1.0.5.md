## 수정 사항

- v1.0.4에서 인터넷 연결 상태와 관계없이 **“앱을 시작할 수 없어요”** 화면에 멈추는 오류 수정
- 앱 초기화에 필요한 파일 누락 수정
- 동일한 파일 누락을 방지하는 빌드 검사 추가
- 홈에서 아래로 스크롤하면 검색·필터 영역을 숨기고, 위로 스크롤하면 다시 표시
- 스크롤 방향이 바뀔 때 헤더가 반복해서 전환되는 현상을 줄이고, 접히고 나타나는 움직임을 부드럽게 조정
- ‘내 글’의 상태 필터와 ‘채팅’의 검색창도 목록을 아래로 내릴 때 숨기고, 위로 올릴 때 다시 표시
