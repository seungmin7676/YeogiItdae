v1.0.4를 설치하면 인터넷에 연결돼 있어도 **“앱을 시작할 수 없어요”** 화면에서 멈추는 문제가 있었습니다. 앱을 만드는 과정에서 필요한 파일이 빠진 것이 원인이었고, 이번 버전에서 수정했습니다. 이용에 불편을 드려 죄송합니다.

기존 앱을 삭제하지 않고 업데이트하면 됩니다. 휴대폰에서 업데이트한 뒤 로그인 상태가 유지되고 물건 목록이 열리는 것까지 확인했습니다.

v1.0.4에서 추가한 채팅 목록의 물건 제목, 채팅방의 물건 카드, 진행 중인 글만 보는 기능도 그대로 사용할 수 있습니다.
