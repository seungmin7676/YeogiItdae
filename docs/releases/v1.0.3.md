## 변경 사항

- 최근 메시지부터 불러오고 이전 대화는 나눠 조회하도록 채팅 로딩 개선
- 푸시 알림 연결 재시도 및 기기별 연결 상태 확인 기능 추가
- 사진 업로드 시간 제한 추가
- 개인정보 보호 및 물건 전달 시 주의사항 안내 추가

## 수정 사항

- 한 글자 검색, 오래된 글, 설명 뒷부분의 검색어가 결과에서 누락되는 문제 수정
- 메시지 전송 오류를 사용자 차단으로 잘못 안내하는 문제 수정
- 차단된 상대에게 사진을 전송하는 처리 보완
- 튜토리얼 확인 기록 저장 실패 시 앱 진입이 막히는 문제 수정
