검색에 빠지는 글이 있거나, 대화가 길어지면 불러오는 데 시간이 걸리던 부분을 손봤습니다.

- 한 글자로 검색하거나 오래된 글을 찾을 때, 검색어가 설명 뒷부분에 있을 때도 결과에 나오도록 수정했습니다.
- 채팅은 최근 대화부터 보여 주고, 위로 올리면 이전 메시지를 불러옵니다.
- 메시지 전송에 실패했을 때 상대방에게 차단당한 것으로 잘못 안내하던 문제를 수정했습니다. 차단된 상대에게 사진을 보내는 처리도 보완했습니다.
- 알림 연결을 다시 시도할 수 있도록 하고, **알림 설정**에서 현재 기기의 연결 상태를 확인할 수 있게 했습니다.
- 사진을 올리다 멈췄을 때 계속 기다려야 하던 문제를 수정했습니다.
- 처음 사용 안내를 봤다는 기록이 저장되지 않아도 앱을 이용할 수 있도록 수정했습니다.
- 사진 속 개인정보와 물건을 건넬 때 주의할 점을 안내에 추가했습니다.
