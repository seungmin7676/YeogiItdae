# 여기있대!

**캠퍼스에서 잃어버린 물건, 여기서 함께 찾아요.**

여기있대!는 한림대학교 구성원을 위한 분실물 찾기 앱입니다.
잃어버리거나 주운 물건을 사진과 함께 올리고, 검색과 채팅으로 주인을 찾을 수 있습니다.
교내 소프트웨어 전시를 위해 제작한 프로젝트로, 현재는 Google Play가 아닌 GitHub에서 Android 설치 파일을 제공합니다.

[최신 버전 받기](https://github.com/seungmin7676/YeogiItdae/releases/latest) · [오류 제보하기](https://github.com/seungmin7676/YeogiItdae/issues)

## 어떤 일을 할 수 있나요?

- **분실물·습득물 등록** — 사진, 물건의 특징, 분실·습득 장소를 함께 기록합니다.
- **검색과 필터** — 검색어, 카테고리, 장소, 분실·습득 여부로 원하는 글을 찾습니다.
- **1:1 채팅** — 글쓴이와 메시지·사진을 주고받으며 물건과 전달 방법을 확인합니다. 채팅방 상단을 누르면 연결된 게시글도 다시 볼 수 있습니다.
- **찜과 알림** — 관심 있는 글을 찜하고, 키워드·카테고리 알림으로 관련 새 글을 확인합니다.
- **내 정보 관리** — 마이페이지에서 내 글·찜한 글을 확인하고, 알림 설정·사용자 차단·튜토리얼 다시 보기를 이용합니다.

## 다운로드 및 설치

현재 설치 파일은 **Android 7.0 이상**에서 사용할 수 있습니다. iPhone용 설치 파일은 제공하지 않습니다.

1. 휴대폰에서 [최신 릴리즈](https://github.com/seungmin7676/YeogiItdae/releases/latest)를 엽니다.
2. 페이지 아래 **Assets**에서 이름이 `YeogiItdae-`로 시작하고 `.apk`로 끝나는 파일을 다운로드합니다. `Source code`는 설치 파일이 아닙니다.
3. 다운로드한 APK를 열어 설치합니다. 설치 출처 허용 안내가 나오면 다운로드에 사용한 브라우저·파일 앱의 설치 권한을 확인하세요. 설치 후에는 해당 권한을 다시 끌 수 있습니다.
4. 앱을 열고 회원가입과 학교 이메일 인증을 진행합니다.

이미 앱이 있다면 삭제하지 말고 새 APK를 실행해 **업데이트 설치**하세요.
현재 v1.0.3은 이전 배포본과 같은 서명을 사용합니다.
보안 경고로 설치가 차단되면 보호 기능을 무작정 끄지 말고, 파일 출처와 경고 내용을 확인한 뒤 제보해 주세요.

## 처음 사용하는 방법

1. **학교 이메일로 시작하기** — `@hallym.ac.kr` 계정으로 가입하고 이메일 인증을 완료합니다.
2. **물건 찾기 또는 글 올리기** — 목록에서 검색하거나, 잃어버린 물건·주운 물건의 글을 등록합니다.
3. **채팅으로 확인하기** — 관련 글에서 채팅을 시작하고 물건의 특징과 분실 장소를 확인합니다.
4. **안전하게 전달하기** — 실제 주인인지 확인한 뒤 교내 공개된 장소에서 전달합니다.
5. **내 글 완료 처리하기** — 물건을 찾았거나 주인에게 전달했다면 글의 상태를 완료로 변경합니다.

사용법이 헷갈리면 **마이페이지 → 튜토리얼 다시 보기**에서 안내를 다시 볼 수 있습니다.

## 안전하게 이용해 주세요

- 사진 속 학생증, 카드번호, 연락처 등 개인정보는 가려 주세요.
- 주인 확인에 필요한 특징을 전부 공개하지 말고, 채팅에서 사진에 없는 특징을 물어보세요.
- 학교 이메일 인증은 물건의 실제 소유자라는 보증이 아닙니다. 휴대폰은 소유자가 직접 잠금을 해제하는지 확인하는 등 추가 확인이 필요합니다.
- 채팅으로 비밀번호나 신분증 사진을 요구하거나 보내지 마세요. 확인이 어렵다면 교내 담당 부서에 인계하세요.
- 불편한 사용자는 차단하고, 문제가 있는 글은 신고할 수 있습니다.

## 자주 묻는 질문

### 휴대폰 알림이 오지 않아요

앱 안의 알림 목록과 휴대폰의 푸시 알림은 서로 다릅니다.
**마이페이지 → 알림 설정 → 이 기기의 푸시 알림**에서 연결 상태를 확인하고, 휴대폰에서도 앱 알림을 허용해 주세요.
인터넷 연결이나 배터리 절약 설정에 따라 알림이 늦어질 수 있습니다.

일시적으로 실패한 알림 발송 요청은 발신자가 로그인한 앱을 실행하거나 다시 열었을 때 최대 24시간 동안 재시도합니다.
앱을 계속 꺼 두었거나 기기에서 알림을 차단한 경우에는 즉시 수신을 보장하지 않습니다.

### 비밀번호를 잊었어요

로그인 화면에서 **비밀번호를 잊으셨나요?**를 선택해 재설정하세요.

### 사진이나 목록이 불러와지지 않아요

인터넷 연결을 확인한 뒤 화면의 다시 시도 또는 새로고침을 이용해 주세요.
계속 문제가 생기면 **마이페이지 → 버그 신고**로 발생 상황과 화면을 알려 주세요. 비밀번호·인증 코드 등은 첨부하지 마세요.

### 계정을 삭제하고 싶어요

**마이페이지 → 회원 탈퇴**에서 진행할 수 있습니다.
탈퇴하면 계정, 게시글, 본인이 보낸 채팅과 업로드 이미지 등이 삭제되며 되돌릴 수 없습니다.
탈퇴 전 앱에 표시되는 삭제 범위와 재가입 제한 안내를 확인해 주세요.
자세한 내용은 [계정 삭제 안내](web/delete-account.html)와 [개인정보 처리방침](web/privacy.html)을 참고하세요.

## v1.0.3에서 달라진 점

- 한 글자 검색, 오래된 글, 설명 뒷부분의 검색어가 누락되던 문제를 보완했습니다.
- 채팅 기록을 나눠 불러와 대화가 길어져도 처음부터 전부 읽지 않도록 했습니다.
- 채팅 전송 오류와 사진 전송 처리를 보완했습니다.
- 푸시 알림 재시도와 기기별 알림 연결 상태 확인을 추가했습니다.
- 사진 업로드가 오래 멈추는 상황과 튜토리얼 저장 실패 시 앱 진입 문제를 보완했습니다.
- 사진 첨부와 물건 전달 시 개인정보·소유자 확인 안내를 추가했습니다.

실제 Android 휴대폰의 푸시 수신은 추가 확인이 필요합니다. 기기·네트워크 환경에 따라 동작이 달라질 수 있는 전시용 앱입니다.
