# 여기있대!

학교에서 잃어버린 물건을 찾고, 주운 물건의 주인을 찾아주는 앱입니다.
한림대학교 이메일로 가입해 분실물이나 습득물 글을 올리고, 글쓴이와 채팅으로 연락할 수 있습니다.

[웹에서 사용하기](https://yeogi-itdae.web.app) · [Android 앱 받기](https://github.com/seungmin7676/YeogiItdae/releases/latest)

## 시작하기

설치 없이 쓰려면 [웹 버전](https://yeogi-itdae.web.app)에 접속하면 됩니다. PC와 휴대폰 모두 사용할 수 있고, 앱에서 쓰던 계정으로 로그인하면 게시글과 채팅도 그대로 이어집니다. iPhone에서도 웹으로 이용할 수 있습니다.

Android 앱은 [다운로드 페이지](https://github.com/seungmin7676/YeogiItdae/releases/latest)의 **Assets**에서 `.apk` 파일을 받아 설치해 주세요. Android 7.0 이상이 필요합니다. 설치가 막히면 파일을 연 브라우저나 파일 앱의 **알 수 없는 앱 설치**를 허용해 주세요. 이미 앱을 쓰고 있다면 삭제하지 않고 새 파일을 열어 업데이트하면 됩니다.

처음 가입할 때는 학교 이메일(`@hallym.ac.kr`)이 필요합니다. 회원가입 후 학교 메일로 받은 인증 코드를 입력해 주세요. 메일이 보이지 않으면 스팸함도 확인해 보세요.

## 물건을 잃어버렸다면

홈에서 **습득물**을 선택해 다른 사람이 주운 물건을 찾아보세요. 물건 이름이나 특징을 검색하거나, 장소와 카테고리로 범위를 좁힐 수 있습니다. **진행 중만**을 켜면 이미 완료된 글은 제외됩니다.

내 물건으로 보이는 글이 있으면 사진과 설명을 확인한 뒤 **채팅하기**로 연락해 주세요. 아직 올라온 글이 없다면 **글쓰기**에서 분실물 글을 남겨 보세요. 잃어버린 장소와 물건의 특징을 적어 두면 찾는 데 도움이 됩니다.

## 물건을 주웠다면

**홈 → 글쓰기 → 습득물**에서 사진과 발견 장소를 올려 주세요. 연락이 오면 채팅으로 물건의 특징을 확인하고 전달할 장소를 정하면 됩니다.

물건을 돌려줬거나 되찾았다면 **내 글**에서 해당 글을 열고 **거래완료로 표시**를 눌러 주세요.

학생증이나 카드 사진에는 이름·번호 등 개인정보가 보이지 않게 가려 주세요. 물건을 건네기 전에는 사진에 나오지 않은 특징도 확인해 보는 게 좋습니다.

## 알아두면 편한 기능

- 다시 보고 싶은 글은 **찜**해 두면 마이페이지에서 모아 볼 수 있습니다.
- **마이페이지 → 키워드 알림**에 물건 이름이나 카테고리를 등록하면 관련된 새 글의 알림을 받을 수 있습니다.
- 채팅 목록에는 상대방 이름과 함께 물건 제목이 표시됩니다. 대화 중에도 위쪽의 **게시글 보기**를 눌러 물건을 다시 확인할 수 있습니다.
- 알림 종류는 **마이페이지 → 알림 설정**에서 바꿀 수 있습니다. 알림이 오지 않으면 휴대폰이나 브라우저에서도 알림을 허용했는지 확인해 주세요.
- 처음 사용 안내는 **마이페이지 → 튜토리얼 다시 보기**에서 다시 볼 수 있습니다.

## 문의와 프로젝트 정보

쓰다가 오류를 발견하면 앱의 **마이페이지 → 버그 신고**나 [GitHub 이슈](https://github.com/seungmin7676/YeogiItdae/issues)로 알려 주세요. 어떤 화면에서 무슨 일이 있었는지 적어 주시면 확인에 도움이 됩니다. 불편한 게시글이나 사용자는 앱에서 신고·차단할 수 있습니다.

계정 삭제는 **마이페이지 → 회원 탈퇴**에서 할 수 있습니다. 자세한 내용은 [계정 삭제 안내](https://yeogi-itdae.web.app/delete-account.html)와 [개인정보 처리방침](https://yeogi-itdae.web.app/privacy.html)을 참고해 주세요.

여기있대!는 교내 소프트웨어 전시를 위해 Flutter로 만든 프로젝트입니다. 버전별로 달라진 점은 [릴리즈](https://github.com/seungmin7676/YeogiItdae/releases)에, 직접 실행하는 방법은 [개발자 가이드](docs/DEVELOPMENT.md)에 정리해 두었습니다.
