# 여기있대!

한림대학교 구성원을 위한 분실물·습득물 공유 서비스입니다.
교내 소프트웨어 전시 프로젝트로 제작했으며, 웹과 Android 앱에서 동일한 계정으로 이용할 수 있습니다.

[웹 서비스](https://yeogi-itdae.web.app) · [Android 다운로드](https://github.com/seungmin7676/YeogiItdae/releases/latest) · [릴리즈](https://github.com/seungmin7676/YeogiItdae/releases)

## 주요 기능

- **분실물·습득물 게시판**: 사진과 장소를 포함한 게시글 등록, 수정, 삭제, 완료 처리
- **검색 및 필터**: 물건 이름·설명 검색, 장소·카테고리별 조회, 진행 중인 글만 보기
- **채팅**: 게시글 작성자와 메시지·사진 전송, 대화 중인 물건 정보 확인
- **찜 및 알림**: 관심 게시글 저장, 키워드·카테고리별 새 글 알림, 채팅 알림 설정
- **계정 관리**: 학교 이메일 인증, 프로필 수정, 사용자 신고·차단, 회원 탈퇴

## 이용 환경

- 한림대학교 이메일(`@hallym.ac.kr`) 인증 필요
- 웹: PC 및 모바일 브라우저
- Android 앱: Android 7.0 이상
- iPhone: 웹 서비스 이용

웹과 앱의 게시글, 찜, 채팅은 같은 계정으로 연동됩니다.

## 설치 및 가입

### 웹

[yeogi-itdae.web.app](https://yeogi-itdae.web.app) 접속 후 회원가입 또는 로그인.

### Android

1. [최신 릴리즈](https://github.com/seungmin7676/YeogiItdae/releases/latest)의 **Assets**에서 `.apk` 파일 다운로드
2. 다운로드한 파일 실행 및 설치
3. 설치 권한 안내가 표시되는 경우 해당 브라우저 또는 파일 앱의 **알 수 없는 앱 설치** 허용

기존 앱이 설치된 경우 삭제 없이 새 APK로 업데이트할 수 있습니다.

### 회원가입

1. 학교 이메일과 기본 정보 입력
2. 학교 메일로 수신한 인증 코드 입력
3. 인증 완료 후 로그인

## 사용 방법

| 화면 | 기능 |
| --- | --- |
| 홈 | 분실물·습득물 검색, 필터 설정, 게시글 작성 |
| 내 글 | 작성한 게시글 관리 및 완료 처리 |
| 채팅 | 게시글 작성자와 대화, 물건 정보 및 전달 상태 확인 |
| 마이페이지 | 프로필, 찜한 글, 키워드 알림, 알림 설정, 차단 목록 관리 |

물건을 찾거나 전달한 뒤에는 해당 게시글에서 **거래완료로 표시**를 선택합니다.
