# 여기있대!

**캠퍼스에서 잃어버린 물건, 여기서 함께 찾아요.**

여기있대!는 **한림대학교 구성원을 위한 분실물 찾기 앱**입니다.
잃어버린 물건이나 주운 물건을 사진과 함께 올리고, 글쓴이와 채팅하며 물건을 찾거나 주인에게 돌려줄 수 있어요.

| 이런 상황이라면 | 이렇게 이용해 보세요 |
| --- | --- |
| 물건을 잃어버렸어요 | 다른 사람이 올린 **습득물**을 찾아보고, **분실물** 글을 올려요. |
| 주인을 모르는 물건을 주웠어요 | **습득물** 글을 올려 주인을 찾아요. |
| 내 물건 같은 글을 발견했어요 | 게시글의 **채팅하기**를 눌러 글쓴이에게 연락해요. |

[웹에서 바로 사용하기](https://yeogi-itdae.web.app) · [Android 앱 다운로드](https://github.com/seungmin7676/YeogiItdae/releases/latest) · [버전별 변경 내역](https://github.com/seungmin7676/YeogiItdae/releases) · [오류 제보](https://github.com/seungmin7676/YeogiItdae/issues)

## 설치 없이 웹에서 시작하기

PC나 휴대폰 브라우저에서 **[yeogi-itdae.web.app](https://yeogi-itdae.web.app)**을 열어 주세요.
기존 앱 계정으로 로그인할 수 있고, 게시글·찜·채팅은 앱과 함께 사용할 수 있어요.
처음이라면 회원가입 후 학교 이메일(`@hallym.ac.kr`) 인증을 진행해 주세요.

웹 알림은 브라우저가 지원하는 환경에서 **마이페이지 → 알림 설정**을 통해 허용할 수 있어요.

## Android 앱 설치하고 시작하기

**Android 7.0 이상인 휴대폰과 한림대학교 이메일(`@hallym.ac.kr`)이 필요해요.**
현재 앱 설치 파일은 GitHub에서 제공하며, iPhone용 설치 파일은 제공하지 않습니다.

1. 휴대폰에서 [앱 다운로드 페이지](https://github.com/seungmin7676/YeogiItdae/releases/latest)를 열어요.
2. **Assets**에서 이름이 `YeogiItdae-`로 시작하고 `.apk`로 끝나는 파일을 받아요. `Source code`는 앱 설치 파일이 아니에요.
3. 받은 파일을 열어 설치해요. 설치 출처 허용 안내가 나오면 다운로드에 사용한 브라우저나 파일 앱의 권한을 확인해 주세요.
4. 앱에서 **회원가입**을 누르고 학교 이메일, 닉네임 등 필요한 정보를 입력해요.
5. 학교 메일함으로 받은 **인증 코드**를 앱에 입력하면 시작할 수 있어요.

이미 설치했다면 앱을 삭제하지 않고 새 APK를 열어 업데이트할 수 있어요.
설치 파일이 없는 사전 릴리즈는 변경 내역과 소스를 확인하는 용도입니다.

## 물건을 잃어버렸나요?

1. **홈**에서 **습득물**을 선택해 다른 사람이 주운 물건을 살펴봐요.
2. 물건 이름이나 특징을 검색해요. 예를 들어 `검은색 지갑`, `에어팟`처럼 입력해 보세요. 카테고리와 장소로 범위를 좁힐 수도 있어요.
3. 비슷한 물건의 글을 열어 사진과 설명을 확인하고 **채팅하기**로 연락해요.
4. 아직 찾지 못했다면 홈의 **글쓰기**에서 분실물 글을 올려요. 잃어버린 장소와 물건의 특징을 적으면 찾는 데 도움이 돼요.

찾던 물건과 관련된 새 글을 받고 싶다면 **마이페이지 → 키워드 알림**에 검색어를 등록해 보세요.

## 물건을 주웠나요?

1. **홈 → 글쓰기**에서 **습득물**을 선택해요.
2. 사진, 물건 이름, 발견 장소와 설명을 입력해 등록해요.
3. 연락이 오면 채팅으로 물건의 특징을 확인하고 전달 장소를 정해요.
4. 주인에게 돌려줬다면 **내 글**에서 해당 게시글을 열고 **거래완료로 표시**를 눌러요. 잃어버린 물건을 되찾았을 때도 같은 방법으로 완료할 수 있어요.

학생증·카드번호·연락처는 사진에서 가려 주세요. 전달 전에는 사진에 공개하지 않은 특징을 물어보고, 교내 공개된 장소에서 만나 주세요.

## 화면별로 할 수 있는 일

| 화면 | 이용 방법 |
| --- | --- |
| **홈** | 분실물·습득물을 검색하고, 장소·카테고리·정렬 조건으로 찾아요. **진행 중만**을 선택하면 완료된 글을 제외해요. 새 글도 이곳에서 작성해요. |
| **내 글** | 내가 올린 글을 모아 보고 수정·삭제하거나 완료 처리해요. |
| **채팅** | 글쓴이와 메시지·사진을 주고받아요. 목록에서 물건 제목, 최근 대화, 시각과 진행 상태를 함께 확인해요. |
| **마이페이지** | 프로필, 찜한 글, 키워드 알림, 알림 설정과 차단 목록을 관리해요. |

## 대화하면서 물건 확인하기

- **어떤 물건에 대한 대화인지 확인해요.** 채팅방 위쪽에 물건 사진과 제목이 표시되고, **게시글 보기**를 누르면 원래 글을 열 수 있어요.
- **이전 대화를 편하게 읽어요.** 날짜 구분선으로 대화한 날을 구별할 수 있어요. 이전 메시지를 읽는 중 새 메시지가 오면 **새 메시지** 버튼을 눌러 최신 대화로 이동해요.
- **진행 상황을 확인해요.** 채팅 목록과 물건 카드에서 진행·확인·전달 완료 상태를 볼 수 있어요. 삭제된 게시글은 삭제 상태로 안내해요.

## 관심 있는 글과 알림

다시 보고 싶은 게시글은 **찜**해 두세요. **마이페이지 → 찜한 글**에서 모아 볼 수 있어요.

**마이페이지 → 키워드 알림**에서는 관심 있는 검색어와 카테고리를 등록할 수 있어요.
어떤 알림을 받을지는 **마이페이지 → 알림 설정**에서 선택해요.

## 자주 묻는 질문

### 인증 메일이 보이지 않아요

가입할 때 입력한 학교 이메일과 스팸 메일함을 확인해 주세요.
인증 화면에서 재전송할 수 있게 되면 코드를 다시 요청해 보세요.

### 비밀번호를 잊었어요

로그인 화면에서 **비밀번호를 잊으셨나요?**를 눌러 재설정해 주세요.

### 휴대폰 알림이 오지 않아요

**마이페이지 → 알림 설정 → 이 기기의 푸시 알림**에서 연결 상태를 확인해 주세요.
휴대폰 설정에서도 여기있대!의 알림을 허용해야 해요. 인터넷 연결이나 배터리 절약 설정에 따라 알림이 늦어질 수 있어요.

### 사용 방법을 다시 보고 싶어요

**마이페이지 → 튜토리얼 다시 보기**에서 처음 안내를 다시 볼 수 있어요.

### 오류가 나거나 불편한 사용자가 있어요

앱 오류는 **마이페이지 → 버그 신고**로 알려 주세요. 발생한 상황과 화면을 함께 적으면 확인에 도움이 돼요.
문제가 있는 게시글은 신고할 수 있고, 불편한 사용자는 차단할 수 있어요.

### 계정을 삭제하고 싶어요

**마이페이지 → 회원 탈퇴**에서 진행할 수 있어요. 탈퇴 전 화면에 표시되는 삭제 범위와 재가입 제한 안내를 확인해 주세요.
자세한 내용은 [계정 삭제 안내](web/delete-account.html)와 [개인정보 처리방침](web/privacy.html)을 참고하세요.
